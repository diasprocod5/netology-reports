#### 6 Ответы на вопросы:
`preemptible = true` - дешевле непрерываемой, облако может остановить её в любой момент. Данные сохраняются.
`core_fraction = 5` - минимум гарантированной мощности CPU (5%), дёшево, достаточно для учебных задач.
